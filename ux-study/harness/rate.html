what to look for
  1. Loading state visible within 300 ms of starting an action
  2. Primary action disabled or deduplicated while pending (use click 3x fast)
  3. Progress shown where the API gives it (upload %, job progress)
  4. Cancel available for long-running actions
  5. On failure, the message is specific and next to the relevant element
  6. On failure, a recovery path exists without reloading
  7. API field errors land on the right fields
  8. Live state updates without a manual refresh
  9. Navigating away or closing a dialog mid-action leaves the UI consistent
  10. Success state is not shown before the server confirms
